Featured Projects

Two standout projects selected by the Expo review panel.

Featured

ConverseAI

An AI-powered customer service chatbot that uses natural language processing to understand and respond to user queries. The system classifies intent, retrieves relevant knowledge-base articles, and escalates complex issues to human agents. Trained on a curated corpus of support conversations, it achieves strong accuracy across common support scenarios.

Featured

Fortress

A cybersecurity platform demonstrating secure file transfer and data protection. It implements end-to-end encryption, real-time intrusion detection, and automated threat analysis across a simulated corporate network. The project includes a live dashboard for monitoring security events and a hardened container deployment model.

All Projects

The full collection of student technology projects on display.

GridLink

A responsive student portfolio platform built with a Node.js and Express backend and a React frontend. It supports user authentication, project uploads, markdown rendering, and a dark/light theme toggle, all wrapped in a fully responsive layout.

Orbital Colonies

A multiplayer space strategy game built in Unity. Players manage resources, colonize planets, and negotiate trade routes in a shared galaxy with procedural star systems. The project demonstrates networking, AI opponent behaviour, and procedural world generation.

Insight Analytics

A software engineering project delivering a business intelligence dashboard for analysing sales data. Built with Java and Spring Boot, it ingests CSV exports, computes aggregated metrics, and presents interactive charts through a clean web interface with role-based access control.

Secure Vault

A cybersecurity project demonstrating a zero-trust password manager. It stores encrypted credentials client-side, supports multi-factor authentication, and includes a breach-monitoring service that alerts users when their credentials appear in known data leaks.

Code Companion

A web development project: an interactive code-learning platform with a live editor, syntax highlighting, and instant execution of student code in a sandboxed environment. It tracks progress through guided exercises and provides immediate feedback on syntax and logic errors.
