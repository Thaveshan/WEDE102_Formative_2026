Discover Student Innovation

The annual AIE Student Innovation Expo celebrates creativity, technical excellence and practical problem-solving across multiple technology disciplines.

This year's Expo features over 40 student projects developed throughout our bachelor's and master's programs. From AI-powered chatbots and cybersecurity platforms to immersive games and innovative web applications, students demonstrate their ability to transform ideas into working prototypes using industry-standard tools and methodologies.

Visitors can explore project demonstrations, interact with working prototypes, and engage directly with the student developers who built them. The Expo highlights not only technical skills but also teamwork, project management, and communication abilities essential for success in the technology industry.

What You Will Find Here

  • Artificial Intelligence: Machine learning models, natural language processing applications, computer vision systems, and AI-powered decision support tools.
  • Cybersecurity: Network security platforms, encryption tools, vulnerability scanners, and secure authentication systems designed to protect digital assets.
  • Software Development: Desktop applications, mobile apps, and enterprise software solutions built with modern programming languages and frameworks.
  • Web Development: Responsive websites, progressive web applications, and web APIs utilizing HTML5, CSS3, JavaScript, and backend technologies.
  • Game Development: 2D and 3D games, interactive simulations, and game mechanics developed using Unity, Unreal Engine, and custom game frameworks.
